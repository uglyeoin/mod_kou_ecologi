# Changelog

## 2.0.0 (October 2026)

- Rewritten for Joomla 5 and 6: namespaced module, Web Asset Manager, no legacy code.
- Uses Ecologi's current impact endpoint: trees, carbon offset, carbon removal and habitat restoration.
- Counter cards, badge and sentence layouts; style options and optional count-up.
- Results cached, with the last figures shown if Ecologi is down.
- Accessible markup; all output escaped; message for site managers when not configured.
- Settings from 0.0.x carried across on upgrade.

## 0.0.9 (2021)

- Trees and carbon offset from the Ecologi public API.
